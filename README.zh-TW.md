# Capability Value Test｜新能力價值驗證

> 讓新能力的使用過程可以被看見，讓新能力創造的價值可以被衡量。

Capability Value Test 是一個面向 AI Agent 的通用 Skill，用來驗證一項新接入能力（如 Skill、模型、外掛、MCP Server、瀏覽器、開源元件或 Agent 工作流程）是否真的被呼叫，以及它相較於原有方法是否創造了可衡量的價值。

它會在原有做事方法與接入新能力後的方法之間設計公平的 A/B Test。實驗預設包含三輪，任務樣本來自使用者平時常做的工作、常用情境或直接提供的案例。完整方案必須先經過人類審核，核准後才會執行，最後產出獨立、視覺化且可追溯的 HTML 報告。

## 它要回答的問題

1. **新能力真的被呼叫了嗎？證據在哪裡？**
2. **它真的帶來價值嗎？能否量化？**
3. **人類能否用視覺化方式理解使用過程與具體價值？**

## 執行流程

1. 定義新能力，以及接入前後的兩種做事方法。
2. 從使用者常做的工作中選擇三個有代表性的任務樣本。
3. 每輪讓兩種方法使用相同輸入、輸出要求、停止條件與評估標準。
4. 將完整實驗方案交給人類審核；未通過就修改後重新提交。
5. 核准後分別執行三輪原方法與新方法，記錄結果、指標與呼叫證據。
6. 分析差異並產生獨立 HTML 報告。

目標不是讓新能力獲勝，而是確認它帶來了什麼改變，以及證據是否足以支持採用。

## HTML 報告

報告會展示：

1. **頂部決策摘要**：直接展示兩種方法、最終建議、主要原因、價值問題與測試日期。
2. **核心對比與實驗分析**：展示三輪總體資料、逐輪結果、實驗觀察、外部資料、優劣勢、具體使用情境與不確定性。
3. **實驗設計與證據**：說明任務依據、公平條件與判斷標準；每輪可展開左右時間線，模型、工具與原始日誌附在實際發生的節點中。

無法取得的指標會顯示「不可用」，不會被當作零。所有敏感資訊必須先移除。

## 安裝

```bash
npx -y skills add EthanZhu-07/capability-value-test -g --all
```

或複製儲存庫，再依照所使用 Agent 的 Skill 目錄規則安裝：

```bash
git clone https://github.com/EthanZhu-07/capability-value-test.git
```

## 使用

```text
請使用 Capability Value Test，比較原本的瀏覽器方法與接入 Lightpanda 後的方法。先把實驗方案交給我確認，不要直接執行。
```

## 手動產生報告

```bash
python3 scripts/render_report.py tests/sample-experiment.json --output report.html
```

渲染器只使用 Python 標準函式庫，輸出可離線開啟的單一 HTML 檔案。

最新版使用帶版本號的固定報告格式。每份報告保持相同的區塊與順序，並在每個主要標題下保留解釋文字。報告預設使用使用者的對話語言，可在右上角切換語言；分析會清楚區分實驗結果、帶來源的外部資料與綜合建議，並以具體人物、任務和環境描述適用情境。

## 限制

- 三輪代表性任務可以降低單次偶然性，但仍只能提供任務範圍內的方向性證據。
- 每輪中兩種方法必須使用相同輸入與判斷標準。
- Token 與成本只有在宿主提供時才能比較。
- 無法驗證新能力被呼叫時，結論必須是「證據不足」。
- 無頭執行會呈現為執行記錄，不會被冒充為即時錄影。
